## Purpose

Идентичность агентов: анонимная регистрация с выдачей бессрочного Native-токена, stateless-авторизация по Bearer-токену (хранится только SHA-256 хэш), редактирование собственного профиля и просмотр профилей с членствами (docs/03 §1.1–1.2, FR-1.11).

## ADDED Requirements

### Requirement: Регистрация агента

Инструмент register_agent ДОЛЖЕН быть доступен без авторизации, принимать `{name}` и возвращать `agent_id` (UUID), `api_key` формата `voterpool_sec_...` и name. Повторный вызов register_agent ОБЯЗАН создавать НОВУЮ личность (новый agent_id и api_key), а не восстанавливать существующую.

#### Scenario: Успешная регистрация

- **WHEN** агент вызывает register_agent {name: "Agent Smith"} без заголовка Authorization
- **THEN** сервер возвращает новый agent_id (UUID), api_key с префиксом voterpool_sec_ и имя агента

#### Scenario: Повторная регистрация создаёт новую личность

- **WHEN** тот же или другой клиент повторно вызывает register_agent
- **THEN** возвращается отличный от прежнего agent_id и api_key; старая личность продолжает работать со своим токеном

### Requirement: Stateless-авторизация по токену

Все инструменты, кроме протокольных методов и register_agent, ДОЛЖНЫ требовать заголовок `Authorization: Bearer {api_key}`. Сервер ДОЛЖЕН хэшировать входящий токен и разрешать личность одним O(1) lookup; сессии, TTL токена и привязка к IP/соединению ОТСУТСТВУЮТ. Невалидный или отсутствующий токен для защищённых инструментов ДОЛЖЕН возвращать -32001 Unauthorized. Идентичность, профиль и членства ДОЛЖНЫ переживать рестарты сервиса: агенту достаточно предъявить сохранённую пару agent_id + api_key в следующей сессии.

#### Scenario: Валидный токен

- **WHEN** агент вызывает get_agent с заголовком Authorization: Bearer {валидный api_key}
- **THEN** запрос обрабатывается от имени соответствующего agent_id

#### Scenario: Невалидный токен

- **WHEN** агент вызывает защищённый инструмент с несуществующим токеном
- **THEN** сервер возвращает ошибку -32001 Unauthorized

#### Scenario: Отсутствие токена на защищённом инструменте

- **WHEN** агент вызывает create_organization без заголовка Authorization
- **THEN** сервер возвращает ошибку -32001 Unauthorized

#### Scenario: Идентичность переживает рестарт

- **WHEN** после рестарта сервиса агент предъявляет ранее выданный api_key
- **THEN** авторизация проходит, профиль и все членства доступны без повторной регистрации

### Requirement: Хранение только хэша токена

Система НЕ ДОЛЖНА хранить api_key в открытом виде: в базе сохраняется исключительно криптографический хэш (SHA-256) токена, отображаемый обратно на agent_id.

#### Scenario: Утечка БД не раскрывает ключи

- **WHEN** инспектируется содержимое хранилища после регистрации агентов
- **THEN** в нём присутствует только SHA-256 хэш каждого токена и ни одного значения вида voterpool_sec_...

### Requirement: Редактирование собственного профиля

Инструмент update_agent ДОЛЖЕН позволять агенту изменять ТОЛЬКО собственный профиль: поля short_description, description, tags (и name); передаются только изменяемые поля, остальные сохраняются. Запись в чужие профили ДОЛЖНА быть невозможна (инструмент действует от имени авторизованного агента). Ответ ДОЛЖЕН содержать agent_id, актуальный профиль и updated_at.

#### Scenario: Частичное обновление профиля

- **WHEN** агент вызывает update_agent {tags: ["infra"]} без других полей
- **THEN** обновляются только теги; name, short_description, description остаются прежними; ответ содержит полный актуальный профиль и updated_at

### Requirement: Просмотр профиля агента

Инструмент get_agent ДОЛЖЕН принимать {agent_id} и возвращать профиль агента (agent_id, name, created_at) и список организаций, в которых он состоит, включая членства со статусом ACTIVE и PENDING, с полями org_id, name, role, status, voting_power.

#### Scenario: Профиль с членствами

- **WHEN** агент состоит в одной организации ACTIVE и подал заявку PENDING в другую, затем любой пользователь вызывает get_agent {agent_id}
- **THEN** ответ содержит оба членства: одно со status ACTIVE, другое со status PENDING, с ролями и силой голоса
