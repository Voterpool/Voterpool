## 3. Подсказка при опечатке во флаге

- [x] 3.1 В обработчике неизвестной опции нормализовать кандидат снятием ведущих `-` и сверить со списком известных имён; при совпадении дополнить вывод «did you mean --<name>?». Проверка: `./build.sh -yes` → «Unknown option: -yes» + подсказка про `--yes`, код возврата 1; `./build.sh --yess` → без ложной подсказки. → Выполнено; оба сценария проверены на реальном скрипте.
- [x] 3.2 Гард интерактивного режима (найден при верификации): обёртка `confirm … || { … }` отключает `set -e` внутри `ask()`, поэтому неудачный `read </dev/tty` (запуск без терминала и без `--yes`) молча давал ответ по умолчанию «Y» и запускал установку. Добавлена явная обработка: неудача чтения → `err "Interactive input unavailable (no terminal); rerun with --yes."` + exit 1. Проверка: форк-прогон без терминала завершается rc=1 с этим сообщением до любых попыток установки.
